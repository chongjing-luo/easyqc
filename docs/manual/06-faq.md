# 06 常见问题

按现象分组,每条给原因和处理。没找到再翻 07 附录或 docs/guide 主题文档。

## 导入与名单

**"质控名单缺少 easyqcid / 包含空白 / 包含重复"**
草稿里没有这一列、有空值或重号。导入表格的先在 Excel/草稿里把这一列弄干净;目录导入的用"新增列"公式拼一个唯一编号。

**"质控名单字段与常量冲突"**
某列名和项目常量重名了(两者共用命令变量空间)。改列名或改常量名,二选一。

**想导入的表格列名乱七八糟**
导入后列名=字段名,没有图形化映射;先在草稿里"重命名列",再写入。

**导入后某些行少了**
多半用了"追加行 + 跳过已存在"——同 easyqcid 的旧行被保留了(这是想要的);写入前页面会预告"匹配 N / 新增 N",看一眼再确认。

**"质控前名单不能删除/重命名 easyqcid"**
设计如此,这列是主键。要换个编号规则,新增一列新编号→写入时替换,或重建名单。

## 命令与查看器

**图打不开,弹"查看器启动后立即退出"**
看弹窗或"命令输出"面板里的报错:九成是路径拼错。按序查常量值→该行的路径列→在终端手动跑同款命令。技巧:名单右键"仅执行命令"单测一条。

**命令里想用 `$HOME`、`$(date)` 之类的系统符号**
可以,但模块要选 **Shell** 方式(03 章 §3.3)。选"直接"时这些符号不会被 shell 解释。

**两条命令只执行了一条**
普通换行不分命令;多条命令要用 `MULTICMD` + 单独一行 `;|` 的写法(03 章 §3.2 例 3)。

**换一条数据,旧窗口还留着**
模块里勾选"重新启动前关闭由 EasyQC 管理的查看器";或对比需要同屏时手动关。

**提示"命令包含未闭合的双引号"**
"直接"方式对引号敏感:补齐引号,或这条命令确实含 shell 语法就切 Shell。

## 评分与保存

**同一条评了两次,前一次哪去了**
被覆盖了。同一(条目、模块、评分者)只保留最后一次保存,这是明确设计:改判就直接重存。

**旧记录打开是只读,提示"评分结构与当前模块不一致"**
模块的评分项/选项后来改过。两个选择:用"已有质控记录"按当时结构打开修改;或把模块选项改回旧样子再打开。

**保存报"另一进程正在写"**
同一个项目被第二个 EasyQC 窗口开着。关掉另一个窗口再保存;软件宁可报错也不冒并发覆盖的险。

**没保存就点了下一条 / 关窗口**
会被拦下提示;这是防丢分的保险,不是故障。

**想让别人看但不能改**
模块评分者留空(观察模式),或 QC 窗口勾"只读"。

## 结果

**结果页是空的**
先刷新(F5);再确认长表模式只显示**有评分**的行——想看全部换宽表(没评分的行保留、格子空白)。

**宽表里某列数字变成空白**
该条目没被这个模块评过(可能被模块筛选排除了,或还没评到);不是数据丢失。

**删错名单行,评分还能找回来吗**
能。评分文件没被删;把条目重新导回名单(合并列/追加),评分自动重新出现。

**导出的 CSV 在 Excel 里中文乱码**
文件是 UTF-8 无 BOM。用"数据→从文本/CSV"按 UTF-8 导入,或用 WPS/R/pandas 直接读。

**想对比两个评分者的不一致**
长表最合适:同一 easyqcid 会有每人一行,按条目排序后肉眼比,或导出后在统计软件里做一致性分析。

## 项目与协作

**换电脑怎么迁移**
整个 `easyqc_<项目名>` 文件夹拷走 → 新机器上"导入项目"。(查看器软件要另装,常量里的路径可能要改成新机器的实际路径。)

**两个人能同时开同一个项目吗**
各开各的通常没事(各评各的模块);但两人同时**保存**或同时改名单会被写锁/版本检查拦下一次操作,重试即可。稳妥做法:按模块或评分者分工,或错峰使用。

**项目列表里的项目太多/想清理**
"取消登记"只移出列表不删文件;确定永久不要了,再手动删项目文件夹(先备份评分)。

**忘了评分文件存在哪**
项目文件夹 `RatingFiles/模块名/评分者/` 下,每条一个 JSON;结构和备份说明见附录。
