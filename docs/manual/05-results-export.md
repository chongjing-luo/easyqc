# 05 结果与导出

评分存下来之后,这一章解决四件事:看汇总、找漏评、复查旧记录、导出 CSV。入口:`质控结果` 页。

## 1. 刷新与两种表

打开或怀疑数据变了就点 **刷新结果(F5)**(QC 窗口里有没保存的修改时会拦住,先去保存)。每次刷新都是拿"当前名单 + 所有评分文件"现场重算,不存在过期的中间文件。

**Ctrl+Shift+L 在两种表之间切换:**

| | 长表 | 宽表 |
|---|---|---|
| 一行是 | 一条评分(条目 × 模块 × 评分者) | 一个条目 |
| 适合 | 交给统计软件做长格式分析 | 人眼看全貌、找漏评 |
| 评分列 | `module_name, rater, score1, score2…, tag1…, notes, time` | `模块名.评分者.score1` 等,每个模块-评分者一组 |
| 没评分的条目 | 不出现 | **保留,评分格空白** |

两种表都自带名单的全部列(在前面),筛选、排序、列显示、分页和名单页同一套操作;`easyqcid` 恒在第一列。

## 2. 三个日常用法

**找漏评**:宽表 → 筛选该模块的 score 列"为空" → 剩下的就是没评的;逐条右键"打开质控页"去补。

**看每人评了多少**:宽表筛 `score1 为空`/`非空`分别数行数;或长表按 `module_name + rater` 分组看。

**加一列"纳入决定"**:结果页也能"新增列",用公式把评分和阈值比一比,比如 `=IF([AnatQC.lcj.score1] >= 3, "include", "exclude")`。这列会真的存进名单,导出、后续筛选都能用。

## 3. 复查:从结果回到图

选中一行右键,两条路(04 章 §1 的入口也通向这里):

| 入口 | 用当时的什么 | 场景 |
|---|---|---|
| **打开质控页** | **当前**模块配置 | 继续往下评、按现在的标准重看 |
| **已有质控记录**(选某条评分) | **保存时**的模块配置 | 严格复原当时的评分结构、命令模板和筛选,把当时的图重新打开核对 |

"已有质控记录"默认只读展示;取消只读可以修改并覆盖保存回原文件。即使模块后来改了配置、甚至删掉了,旧记录照样能按当时的样子打开。

> 说明:复查复原的是"当时的配置 + 现在的数据路径"。如果文件被挪走,图会开不出来——软件不会替你保管图像本身。

## 4. 导出 CSV

**Ctrl+E 导出的是你当前看到的**:筛选后的行、排好的顺序、勾选显示的列。所以流程是——先筛、先排、先藏列,再导出。

- 保存对话框里自己起文件名(建议带日期:`qc_wide_20261005.csv`);
- UTF-8 编码、表头一行,Excel/R/pandas 直接可读;
- 大表后台分块写、可取消,导完显示行数;导出的是副本,不影响任何数据。

## 5. 两个容易疑惑的行为

- **从名单里删掉的条目,评分并没丢**:评分文件还在项目文件夹里,只是所有结果视图不再显示;把条目重新导回名单,评分立刻回来。
- **结果表没有单独的存档文件**:它是实时视图。要留档就导出 CSV;要留底就备份项目文件夹(附录)。

> 说明:结果页还有"结果关联"功能——把别的模块的评分列(比如颅骨剥离的结论)拼进当前视图做对照,在工具栏"结果关联"里配置,按向导走即可。
