# EasyQC 用户手册

这本手册按**你实际做事的顺序**组织:先把一个最小任务从头跑到尾,再按四个工作环节逐个展开。每一节都从"你要做什么"开始,步骤在前;个别影响你操作习惯的机制,用"说明"框一句话带过。

## 一页流程

```text
准备数据                配置任务              执行质控              看结果
─────────             ─────────            ─────────            ─────────
新建/导入项目    →      建一个模块      →     启动模块,逐条    →    刷新结果
导入质控名单            · 选哪些条目          看图、打分、保存       长/宽表查看
设数据根目录等常量       · 用什么命令开图                            复查、导出 CSV
                       · 评什么(评分项/标签)
```

你的分工:**图在外部程序里看**(Freeview、MRIcroGL、浏览器等,自己装好);EasyQC 负责"打开哪条数据、记录谁的判断、汇总结果"。

## 开始前记住三条

1. **`easyqcid` 是每条质控记录的身份证**:一行名单 = 一次检查单位(一次扫描、一个访视或一个重建结果都行),列里必须有 `easyqcid` 且不能重复。评分和结果全靠它对号入座。
2. **保存即最终版**:同一条目、同一模块、同一评分者只保留最后一次保存的评分,不存历史。改判就再保存一次。
3. **评分是唯一存档**:结果表不用管、随时重建;真正要备份的是项目文件夹(名单 CSV + 评分 JSON,见附录)。
