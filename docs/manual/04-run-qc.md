# 04 执行质控

模块配好之后,这一章是每天用的一套动作:启动 → 看一条 → 评一条 → 保存 → 下一条;偶尔回头改。

## 1. 三种启动方式

| 方式 | 操作 | 场景 |
|---|---|---|
| 正常开工 | 质控模块页选中模块 → 打开 | 从头按队列过 |
| 从某条数据切入 | 名单/结果页右键某行 → **打开质控页**(或"并执行命令") | 排查、补查时直达 |
| 命令行直达一条 | `./start.sh 项目名 模块名 评分者 条目号` | 桌面快捷方式、脚本调用;注意它同样会开窗口,不是后台跑 |

启动后弹出独立的 QC 窗口。左边队列,右边当前条目 + 打分区,底部命令输出。

## 2. 窗口布局与日常动作

```text
┌────────────┬──────────────────────────┐
│ 队列表      │ 只读□  筛选名单  ◀上一个  下一个▶ │
│ 序号        │ ────────────────────────  │
│ easyqcid   │ 评分项1: [未评][0][1][2][3][4]  │
│ 评分(汇总)  │ 评分项2: [未评][差][一般][好]    │
│ 标签(汇总)  │ 标签: ☐checkdone ☐anatfailed   │
│            │ 备注: [____________]           │
│            │ [保存 Ctrl+S] [保存并下一个 Ctrl+Return] │
├────────────┴──────────────────────────┤
│ 命令输出(可展开)                          │
└───────────────────────────────────────┘
```

| 动作 | 怎么做 |
|---|---|
| 看下一条 | **下一个(Alt+→)**——自动打开该条的图 |
| 跳到某条 | 双击队列里那一行 |
| 评分 | 点选项;第一项"未评"可清空该项 |
| 保存并继续 | **保存并下一个(Ctrl+Return)**——存完自动跳下一条并开图 |
| 只存不跳 | 保存(Ctrl+S) |
| 回头改 | 双击已评的行回去,改完再保存 |

队列里的"评分/标签"列是这条的已存结果汇总:空白 = 还没评,一眼看出漏了谁。

**没保存就换条目会被拦住**(提示先保存或放弃),关窗口前同样会确认——不会一失手丢掉半张评分。

## 3. 评分的三个细节

- **旧评分值**:模块选项改过之后,旧评分里不存在的值会显示成灰色按钮"(旧评分值,不在当前选项中)",看得见、点不动。
- **结构差异较大的旧记录**打开时整条只读,提示"评分结构与当前模块不一致"——想改走 05 章 §4.2 的"已有质控记录"路径,或把模块选项改回去。
- **只读复选框**:手动勾上,本次会话只看不存。给别人演示、请人复核时用;模块评分者留空时它自动生效。

## 4. 保存意味着什么

- 每次保存写下一个独立小文件:`评分文件按 模块/评分者 分文件夹存放`,文件名含条目号(见附录)。**同一条目同一模块同一评分者,后一次保存覆盖前一次,不保留历史**——改判就重存。
- 保存内容不只是分数:评分项及其选项定义、标签、备注、时间、命令模板和**这条实际展开后的完整命令**一起存档。所以几个月后翻旧评分,还能看到"当时是用什么命令看的"。
- 保存失败(极少见,比如同一项目被另一个 EasyQC 窗口占着写锁)会明确报错,不会悄悄丢数据,也不会自动跳下一条。

## 5. 图打不开 / 命令报错

1. 看 QC 窗口底部**命令输出**面板:程序退出码和报错摘录都在;
2. 常见原因按顺序查:**常量路径**拼错 → 名单里这一行的**路径列**值不对 → 程序本身没装好(终端里手动跑一遍同款命令);
3. "打开后立即退出"的提示会直接附上对方的报错文本,多数一眼能定位;
4. 命令输出面板右上"打开日志"可看完整记录(保留 14 天)。

> 说明:想先试命令不评分,用名单页右键的"仅执行命令"——只开图,不产生任何保存。

## 6. 多名评分者

三种常见安排:

- **同一模块换人**:右键名单/结果里的条目 → 打开质控页时选同一模块、改评分者;或命令行 `./start.sh 项目 模块 评分者 条目号`。两人的评分各存各的文件夹,互不覆盖,结果表里各占一列。
- **每人一个模块副本**:复制模块改名(`qc_lcj`、`qc_zy`),评分者各填各的。模块筛选、命令可以同步维护,也可各自调整。
- **观察模式**:模块评分者留空,谁打开都只能看不能存。

> 提醒:软件管记录、不管标尺。多人评分前先统一评分标准(每档什么表现、典型异常长什么样),必要时互相抽查对齐——这是流程问题,不是软件能替你做的。
