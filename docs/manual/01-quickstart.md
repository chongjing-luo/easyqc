# 01 安装与快速上手

目标:装好软件,并把一个最小任务从头跑到尾——建项目、导两条记录、配一个最简单的模块、评两次分、导出结果。做完这一遍,后面每一章你都认识路了。

## 1. 安装与启动

```bash
cd easyqc
./setup.sh            # 创建 .venv 并装依赖(已存在则跳过)
./start.sh            # 启动
```

也可以手动:`source .venv/bin/activate && python easyqc.py`。日常点 `start.sh` 即可。

启动后看到项目选择页。左侧七个导航页,一句话认识:

| 导航页 | 你在这里干什么 |
|---|---|
| 跨项目设置 | 管软件自带的模板(可长期不管) |
| 项目选择 | 建项目、导入项目、换项目 |
| 质控名单导入 | 把数据导成名单 |
| 质控前名单 | 查看、整理名单 |
| 常量设置 | 设所有条目共用的路径(如数据根目录) |
| 质控模块 | 配检查任务 |
| 质控结果 | 看汇总、复查、导出 |

## 2. 五分钟跑通一个最小任务

场景:两个被试文件夹 `/data/demo/A001`、`/data/demo/A002`,里面各有几张图,你只需打开文件夹人工看一眼,打个 0–4 分。

**第 1 步 建项目**:项目选择页 → 新建项目 → 名字填 `demo`。会在磁盘上创建 `easyqc_demo/` 项目文件夹(附录)。

**第 2 步 导名单**:切到 `质控名单导入` → 来源选 **直接输入** → 文本框里敲:

```text
A001 A002
```

(空格、逗号、换行都行)→ 预览出现两行 → 点 **写入质控总名单**,模式用默认的"替换" → 确认。

**第 3 步 设常量**:切到 `常量设置` → 添加常量 → 名字 `data_dir`,值 `/data/demo`。这是所有条目共用的根路径。

**第 4 步 建模块**:切到 `质控模块` → 从模板添加,挑一个最简单的(如 `openCCS_DIR`)复制成可编辑副本,然后改成三处:

- 名字 `demo_qc`,评分者填你的名字(如 `lcj`;**留空就只能看不能存**);
- 命令模板改成:`xdg-open {data_dir}/{easyqcid}`(macOS 用 `open`)——意思是"打开这个被试的文件夹"。花括号里的名字会被当前行的列值和常量替换,详见 03 章;
- 评分项留一项:标签 `quality`,可选值 `0-4`。保存。

**第 5 步 评分**:模块列表选中 `demo_qc` → 打开。QC 窗口左边是队列(A001、A002),右边是打分区。双击 `A001` → 文件夹打开,看图 → 点 `4` → **保存并下一个**(Ctrl+Return)→ 自动跳 A002 并打开 → 打 `3` → 保存(Ctrl+S)。

**第 6 步 看结果**:切到 `质控结果` → 刷新结果。宽表里 A001、A002 各一行,多出 `demo_qc.lcj.score1` 一列就是你的分。Ctrl+E 导出 CSV。

> 说明:结果表不是存出来的文件,是每次刷新时由"名单 + 已保存评分"现算的。所以你随时改名单、随时刷新,结果跟着变;导出 CSV 才是你要带走的产物。
