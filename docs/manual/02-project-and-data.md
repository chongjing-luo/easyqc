# 02 准备项目与数据

这一章解决:建好项目,把你的数据(被试文件夹、已有表格、或一串编号)变成质控名单,并设好共用的数据路径。

## 1. 建项目 / 导入项目 / 换项目

**新建**:项目选择页 → 新建项目。名字用字母、数字、`_ . -`,会创建 `easyqc_<名字>/` 文件夹并自动配好内部结构。

**导入已有项目**(换电脑、接手别人的项目):把整个 `easyqc_<名字>` 文件夹拷到本机 → 项目选择页 → 导入项目 → 选这个文件夹。要求文件夹里有且只有一个 `settings_*.json`(正常使用 naturally 满足)。

**换项目**:项目列表双击打开。

**取消登记**:只从列表里移除,**不删任何磁盘文件**;哪天想用再导入回来。

> 备份和迁移就是备份这个项目文件夹,没有别的数据库。里面是什么见附录。

## 2. 名单:一行 = 一次检查单位

名单是项目里唯一的数据底册(质控前名单页看到的表)。要点:

- **必须有一列 `easyqcid`**,每行唯一——它是评分和结果的对号入座依据。字母、数字、`_ . -`,最长 128 字符,不区分大小写地不能重复(比如 `Sub01` 和 `sub01` 不能同时存在)。
- 一行不必是一个被试:一次扫描、一个访视、一个重建结果都可以是单独一行。怎么拆,取决于你要"按什么单位评分"。
- 其余列随你加:被试号、访视、模态、各种路径、上游算好的指标……列名在下一步配置命令时会直接当变量用(03 章),建议用简短英文。

## 3. 三种导入方式

入口:`质控名单导入` 页。**任何导入都先进草稿**——草稿只是预览区,关掉页面就没了;点"写入质控总名单"才真正动名单。

### 3.1 从文件夹导入(推荐,数据已按目录组织时)

选一个根目录,两种玩法:

**直接下一级文件夹**:根目录下每个子文件夹名变成一行。适合 `/data/CCNP/CCNPPEK0001_01`、`CCNPPEK0002_01` 这种结构。

**模式匹配**(要更深、更挑剔时):五个选项——

| 选项 | 常用取值 | 例子 |
|---|---|---|
| 目标类型 | 目录 / 文件 | 只要文件夹,或只要 `.nii.gz` 文件 |
| 匹配方式 | 开头/结尾/包含/通配符/正则 | 通配符 `sub-*`;正则 `^CCNP\d+_\d+$` |
| 搜索范围 | 仅下一级 / 精确深度 / 任意深度 | "任意深度"配合结尾匹配 `*.mgz` 收集全部 T1 |
| 精确深度 | 1–100 | 范围选"精确深度"时生效 |
| 父目录列 | 默认 `relative_parent` | 输出多一列相对路径,便于后续拼完整路径 |

输出是"条目名 + (可选)父目录"两列,后续用新增列公式拼出完整路径或 easyqcid(§4.2)。

### 3.2 从表格文件导入(已有被试清单/元数据表)

支持 `.csv` `.tsv` `.xlsx` `.xls` `.txt` `.list`。**文件的列名原样变成名单的列名**——没有图形化的列映射界面,要改名在草稿里做(§4.1)。`.txt`/`.list` 是"一行一个值"的单列文件,导入时需要给这一列起个名字。

### 3.3 直接输入

粘贴一串编号,空格、逗号、换行都能分隔,生成单列草稿。临时抽查几条数据时最顺手。

## 4. 在草稿里整理

写入前,草稿页提供的整理手段:

### 4.1 改列名 / 删列 / 删行 / 加空行

重命名列时不能和常量重名(§6)。删除行先设筛选条件再删,有确认。

### 4.2 新增列(从已有列算出新列)

点 **新增列(Ctrl+Shift+D)**,用类 Excel 公式。最常用的三个:

| 你想要的 | 公式例子 |
|---|---|
| 从 `CCNPPEK0001_01` 取被试号 | `=TEXTBEFORE([sublist], "_")` |
| 拼完整路径 | `=[data_col] & "/" & [sublist] & "/anat.nii.gz"`(更推荐用常量拼,见 03 章) |
| 取文件名主干 | `=STEM([nifti_path])` |

列引用一律 `[列名]`;支持 `IF`、`LEFT/RIGHT/MID`、`TRIM`、`ROUND` 等约 27 个函数。写错会当场报错,不会写坏数据。

### 4.3 写入总名单:选对模式

点 **写入质控总名单**,先选写入模式和冲突策略,确认框会告诉你会发生什么:

| 你的情况 | 选 |
|---|---|
| 第一次导入 / 想整个推倒重来 | 替换 |
| 往名单里加新被试,已有的不动 | 追加行 + 跳过已存在的 easyqcid |
| 加新被试,且同名行以新表为准更新 | 追加行 + 替换同名行 |
| 老名单不动,只补一列新信息(如新算的指标) | 按 easyqcid 合并列 + 保留原值 |
| 同上,但新表里非空的值要覆盖旧值 | 按 easyqcid 合并列 + 更新 |

写入前会检查两边名单(easyqcid 是否空、是否重复、列名是否与常量冲突),页面上实时显示"匹配 N 条 / 新增 N 条 / 草稿有问题 N 条"。**任何一步不过,原名单一个字都不改**——放心试。

> 说明:替换、删行都不会删除已保存的评分文件;被删条目的评分只是不再显示,把条目加回名单它就回来(05 章 §5)。

## 5. 名单的日常查看与整理

`质控前名单` 页:**筛选、排序、列显示都只是视图**,不动数据,随便试。真正改数据的是删除行、删除/重命名列、新增列,都有确认。`easyqcid` 这一列不能删、不能改名。

## 6. 常量:所有条目共用的路径

`常量设置` 页,典型的一条:名字 `subjects_dir`,值 `/data/CCNP/fsrecon`。什么时候用常量、什么时候用名单列?

- **整个项目不变的** → 常量:数据根目录、软件安装路径(MRIcroGL、FreeSurfer 等);
- **每条目不同的** → 名单列:被试号、访视、各自的重建目录。

两者在命令里写法相同(03 章 §3),拼在一起定位文件。两条规矩:常量名不能与名单列名重复;常量改了之后**新**开的命令用新值,已保存评分里记录的旧命令不回溯。

> 说明:软件自带一个常量模板库(跨项目设置页),把常用的软件路径存成模板,每个新项目"从模板添加"一下就齐了。

## 7. 自查清单

- [ ] `easyqcid` 列存在、无重复、无空值;
- [ ] 命令里要用到的路径列都在(先想好 03 章的命令需要什么);
- [ ] 共享根路径已设为常量,没混进名单列;
- [ ] 想按模态/批次筛选的,对应列(如 `mod`、`wave`)已经导进来。
